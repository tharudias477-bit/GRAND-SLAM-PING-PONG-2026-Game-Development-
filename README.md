 🏓 Grand Slam Ping Pong 2026

A modern, responsive, single-file HTML5 Ping Pong game featuring custom themes, touch/keyboard controls, immersive sound effects, and smooth gameplay mechanics.

✨ Features
- **Responsive Controls:** Play seamlessly on mobile (Touch & Drag) and laptops (Arrow Keys).
- **Custom Assets:** Styled with a sleek background theme and custom paddle design (`1.1.jpg`).
- **Interactive UI/UX:** Multi-stage user flow including a 3-dot loading screen, animated home preview, instruction guide, and pause/settings modals.
- **Web Audio API:** Built-in sound effects (hits, game over) and a soft background music loop with toggle options.
- **Milestone Celebrations:** Special party/celebration effects (🎉) triggered at milestone scores (10, 20, 30+).

 🚀 How to Play
1. Clone or download the repository.
2. Ensure `1.1.jpg` is in the same directory as `index.html`.
3. Open `index.html` in any modern web browser or host it via Netlify / GitHub Pages!
